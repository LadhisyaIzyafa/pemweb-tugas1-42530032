# Portofolio Carolina Jennata — Tugas 1 Pemrograman Web

Single-page landing page (Tema C: Portofolio Profesional Pengembang Perangkat Lunak),
dibangun dengan HTML5 semantik, CSS Flexbox & Grid, dan pendekatan mobile-first.
Tanpa framework CSS.

## Fitur
- Struktur semantik: header, nav, main, 5 section, article, aside, footer
- Hierarki heading runtut (h1 → h2 → h3), alt deskriptif, aria-label pada navigasi & tautan
- Flexbox untuk navigasi/tombol, CSS Grid untuk layout makro & card grid `repeat(auto-fit, minmax(280px, 1fr))`
- Mobile-first, breakpoint `min-width: 768px` dan `1024px`, tanpa horizontal overflow

## Struktur
```
index.html
css/style.css
assets/images/  (hero.jpg, profil.jpg, proyek-1.svg)
assets/icons/   (sertifikat.svg)
```
